# Headless Reward Model Training Pipeline

**Goal**: Repurpose the unused human crowdsourcing app into a headless, automated pipeline that trains a Reward Model using the DPO datasets exported from `firstory-continuous`.

## Context
Manual crowdsourcing failed because ranking fiction pairs requires too much cognitive effort. However, the underlying Elo-ranking, embedding, and Bradley-Terry reward model infrastructure is highly valuable. We will pivot this repo to ingest the automated AO3 Audience Ground Truth data to train a proxy evaluator.

## Tasks

- [ ] **1. Strip the UI**
  - Remove or deprecate `story_feedback_app.py` (Streamlit UI). The system is now headless.

- [ ] **2. Create DPO Ingestion Script**
  - Create a new entry point `ingest_ao3_dpo.py`.
  - Read the `ao3_dpo_dataset.jsonl` files generated by `firstory-continuous`.
  - Insert these `chosen`/`rejected` pairs directly into the Supabase database, bypassing the need for manual web interaction.

- [ ] **3. Update the Reward Model Trainer**
  - Modify `story_ranking_dataset.py`.
  - Change the `source_weights` configuration to heavily prioritize the automated AO3 empirical data.
  - Ensure the ModernBERT embedding processor (`story_embedding_processor.py`) automatically runs on the newly ingested AO3 stories.

- [ ] **4. Expose the Reward Model as an API/Utility**
  - Create a `score_story.py` utility that loads the trained reward model.
  - It should take a prompt and a generated story text, and output a predicted "Engagement Score" (proxy for Audience Ground Truth).
  - This allows `firstory-continuous` or `story-bench` to evaluate stories *before* publishing them, closing the continuous improvement loop.
